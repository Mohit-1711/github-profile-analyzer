# GitHub Profile Analyzer

A modern and responsive GitHub Profile Analyzer built with **React** and **Tailwind CSS**. Search any GitHub username to view profile information and explore their public repositories in a clean, user-friendly interface.

## 🚀 Features

- 🔍 Search GitHub users by username
- 👤 Display profile information
  - Avatar
  - Name
  - Username
  - Bio
  - Followers & Following
  - Public Repositories
  - Company
  - Location
  - Website
  - Twitter
  - Account Creation Date
- 📂 Browse all public repositories
- ⭐ View repository stars
- 🍴 View repository forks
- 💻 Display primary programming language
- 🔗 Open repositories directly on GitHub
- 🌐 Visit deployed project links (if available)
- 🌙 Light/Dark mode toggle
- ❌ Handles invalid usernames gracefully
- 📱 Responsive design for desktop and mobile

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Mohit-1711/github-profile-analyzer.git
```

Navigate to the project folder:

```bash
cd github-profile-analyzer
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
